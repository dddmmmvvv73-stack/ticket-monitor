# Правила работы с проектом

- Сохранять привычный дизайн сайта и существующие сценарии пользователя.
- Не менять дизайн радикально и не заменять знакомый раздел новым интерфейсом без явного согласования пользователя.
- Новые рабочие функции добавлять в отдельный подраздел, когда они расширяют назначение существующего раздела. «Репертуар → Проекты» сохраняет прежние список, фильтры, карточки и мероприятия; рабочая база находится отдельно в «Репертуар → Моя база».
- Карточка в «Моей базе» использует прежнюю композицию карточки Девятовой: общую обложку и кнопки, мероприятия слева, сведения справа. Новые вкладки и рабочие функции временно размещены справа под «О проекте»; дальнейшую компоновку согласовывать с пользователем.
- При выкладке обновлять код. Рабочие пользовательские данные в `~/tm-server/config` не подменять файлами из папки разработки.
