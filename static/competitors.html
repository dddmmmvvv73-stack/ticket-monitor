Правила по названию работают всегда. Нейросеть заполняет только то, что правила не определили, и запоминает ответы — одно и то же название повторно не отправляется.
Как получить ключ (бесплатно, ~5 минут)
  1. Откройте developers.sber.ru/studio и войдите через Сбер ID.
  2. Создайте проект «GigaChat API» (для физического лица).
  3. В настройках проекта нажмите «Получить ключ» и скопируйте Authorization key — ключ показывается один раз.
  4. Вставьте его сюда, сохраните и нажмите «Проверить подключение».
Сертификат Минцифры, который нужен GigaChat, программа скачает сама при первом подключении и проверит его подлинность. Используется только для соединений с GigaChat.

Отправит в нейросеть мероприятия без полной классификации из уже собранной таблицы — без повторного обхода сайтов.
Как получить ссылку (один раз, ~3 минуты)
  1. Откройте нужную Google Таблицу → меню «Расширения» → «Apps Script».
  2. Удалите всё в редакторе и вставьте код ниже, сохраните.
  3. «Развернуть» → «Новое развертывание» → тип «Веб-приложение». Запуск от имени: «Я», доступ: «Все». Разрешите доступ к таблице.
  4. Скопируйте ссылку веб-приложения (заканчивается на /exec) и вставьте сюда.
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(data.sheet) || ss.insertSheet(data.sheet);
  sheet.clearContents();
  var values = [data.header].concat(data.rows);
  sheet.getRange(1, 1, values.length, data.header.length).setValues(values);
  sheet.setFrozenRows(1);
  return ContentService
    .createTextOutput(JSON.stringify({ok: true, rows: data.rows.length}))
    .setMimeType(ContentService.MimeType.JSON);
}
Лист «Конкуренты» каждый раз перезаписывается целиком. Ссылку не публикуйте: любой, у кого она есть, может записать данные в эту таблицу.
Бронь залов — места, которые площадка не продаёт
Бронь не входит ни в вал, ни в выручку. Авто-бронь — места, занятые во всех мероприятиях зала (нужно минимум 3 мероприятия): так ведут себя служебные и технические места, а не продажи. Ручная — ряды, которые вы отметите сами. Изменения пересчитываются сразу, без повторного сбора.
Залы появятся после сбора — они определяются по схемам мест.
